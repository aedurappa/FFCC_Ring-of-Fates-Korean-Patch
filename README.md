# 파이널 판타지 크리스탈 크로니클 링 오브 페이트 (운명의 고리) 한국어 패치

링 오브 페이트의 비공식 한국어화 프로젝트입니다.

## 대상

- 플랫폼: NDS
- 게임: 링 오브 페이트
  (Final Fantasy Crystal Chronicles - Ring of Fates) <- 한국어 패치 대상 (일본판)
- 언어: 일본어 → 한국어

## 패치 소개

게임 본편 및 내 대사와 메뉴, 시스템 메시지 등을 한국어로 번역하고
폰트 및 이미지 리소스를 수정하여 한국어가 정상적으로 표시되도록 작업했습니다.

## 다운로드

최신 패치는 [Releases](../../releases)에서 받을 수 있습니다.

## 오토 패치 적용 방법

1. RoF_KOR_Patcher.exe를 실행하여 rom을 불러오거나, 롬을 RoF_KOR_Patcher.exe위에 드래그 & 드롭합니다.
2. 자동으로 패치가 진행 된 후 RoF_KOR_Patcher.exe가 있는 루트 폴더에 "원본이름_KOR.NDS"파일이 생성됩니다.
3. 해당 파일로 게임을 즐기시면 됩니다.
※ 반드시 일본판에 적용하세요.

## 주의사항

본 패치는 비영리 팬 프로젝트입니다.
원본 게임 파일은 포함하지 않습니다.

정품 게임을 보유한 사용자가 개인적인 목적으로
이용하는 것을 전제로 배포합니다.
